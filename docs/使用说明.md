## 打开网站

公开地址：<https://dingyuzero.github.io/blcu-statistics-classroom/>。无需账户，无需购买域名。源码：<https://github.com/dingyuzero/blcu-statistics-classroom>。

离线使用：在 [Releases 下载页](https://github.com/dingyuzero/blcu-statistics-classroom/releases/latest) 下载单文件 HTML（资产名 `statistics-classroom-offline.html`，交付文件夹中名为 `统计课堂-单文件.html`）。复制到其他电脑后，用 Edge、Chrome 或 Firefox 打开。不要复制原电脑的 `127.0.0.1` 地址，那只指向本地服务。

单文件内置脚本、样式、公式字体、四份 Markdown 文档和许可证，不需要旁边放其他文件。核心交互不需要联网；外部开源项目和 GitHub 下载链接需要网络。部分聊天软件只会预览 HTML 文本，请先下载，再用浏览器打开。

也提供多文件静态离线 ZIP：解压并保持目录结构，打开 `index.html`。开发时可运行 `python -m http.server 8080 --directory dist`，再访问 `http://localhost:8080/`。网页没有后端，不用填写 API Key。

## 课堂基本操作

1. 基础部分选左侧章节，每章三个演示；高级部分点击“高级心理统计”，按教材 14 章进入，每章两个演示。合计 46 项。
2. 先请学生预测，再调整控制台。图形、公式、结果和数值表随参数更新。
3. 文本数据支持逗号、中文逗号、空格、换行分隔，2–200 个有限数值，范围 −10000 至 10000。输入后点击“应用数据”；调其他参数或刷新图形也会重新读取文本。
4. “重置实验”只重置当前演示。各演示分别记忆最后一次有效参数；分享网址只携带路由，不携带自己的数据。
5. “课堂演示”收起导航，Esc 退出。手机窄屏通过左上角菜单选择章节。
6. 展开数值表后可导出完整 CSV；页面最多显示前 200 行。SVG 图形附参数、公式、图例和署名，可放进 PPT 或矢量编辑器。
7. 非法输入会提示原因，并保留上一次有效结果及导出。首次没有有效结果时，应修正输入或重置。

参数只在本机浏览器存储。浏览器拒绝本地存储时当前页仍可使用，但切换或重开可能不保留参数。在线网站、离线文件、不同浏览器之间不会自动同步。

## 建议课堂路线

**25 分钟：从样本到推断。** 抽样分布（8 分钟）→ 区间覆盖率（8 分钟）→ Welch t（9 分钟）。可把两组 SD 都设为 10、均值差设为 5，再增大 n，此时 d 不变。两组 SD 不等时，合并 SD 的样本量权重变化可能改变 d。

**20 分钟：容易混淆的概率。** 贝叶斯基础率（6 分钟）→ 检验功效（7 分钟）→ 多重比较（7 分钟）。区分给定判断后信号存在的概率、给定预设效应时拒绝的概率、一个家族至少一次误报的概率。

**15 分钟：一条回归线的背后。** 相关异常点（5 分钟）→ 手动残差（5 分钟）→ 分组汇总（5 分钟）。先预测再看图，不把相关方向当作因果证据。

## 模型与边界

- 默认示例和模拟是合成数据。手工数据仅在本机计算；课堂投影不要展示未脱敏个人数据。
- SD=0 时 z 分数未定义。均值 t 区间和 Bootstrap 对常量数据提示，避免把零宽度误读为确定性。
- t 区间的精确覆盖要求独立正态观测。Bootstrap 百分位区间是近似法，不能修复有偏抽样；依赖或聚类资料需相应重抽样单位。
- Wilson 是未作连续性校正的得分区间，不是精确二项区间。Wald 不截断，以展示越界和退化。
- 功效页假设 σ 已知，与 Welch 的未知不等方差模型不同。它使用预设效应规划设计，不判断一次研究结果的真实性。
- 多重比较曲线等式需要独立性；Bonferroni 的控制上界不需要独立性。FWER 与 FDR 不同。
- t 分布 df≤1 无均值，df≤2 无有限方差。有限画幅只显示部分尾部，标注概率包括图外区域。
- 教学交互不替代真实分析中的研究设计、缺失值处理、模型诊断与测量验证。

## 常见问题

**仍看到旧内容？** 在线页用 Ctrl+F5；离线版重新下载。左上角、标题、页脚、导出和文档均署名“北京语言大学 Ding Lab”。

**随机结果不一样？** 保持数据、样本量、重复次数和种子一致即可复现。改变置信水平会复用相同抽样；改变每次样本量会改变随机数分组，不表示嵌套样本。

**没看到下载？** 查看浏览器下载记录或点击提示中的“再次下载”。单文件文档、许可证、SVG 和 CSV 使用本地 Blob 下载，不访问网络。

**如何更新公开站？** 见 [部署说明.md](部署说明.md)。只推送 main 不会更新 gh-pages。

本版检查了本机浏览器的目录版和独立单文件服务。未在另一台实体电脑、所有浏览器或教室设备逐一验收；上课前请在实际设备试用。
