## 统计口径与修改

- 四分位数显式固定 type 7。原 simple-statistics 7.12.1 实现与之相同，这是固定算法的维护改进，不能声称修复旧数值错误。
- 修正“增大样本量效应量必然不变”。Cohen d 的合并 SD 按 n−1 加权；两组 SD 不等时，权重变化可能改变 d。它是描述性标准化差，不替代 Welch 推断。
- Bayes 用未舍入联合概率计算，零分母显示未定义，柱高是期望次数。
- Bootstrap 每次有放回抽 n 个观测，重复 B 次，百分位用 type 7，模拟 SE 用 B−1 分母。常量样本给提示；没有 BCa/簇重抽样/偏倚自动修正。
- 单均值区间用 t 临界值，Wilson 是无连续性校正的得分区间；Wald 原始端点不截断。
- 功效是独立正态、已知 σ 的单样本双侧 z 模型：Φ(−z−δ/SE)+Φ(δ/SE−z)。δ=0 时称为拒绝概率，不把 1−α 称作 II 类错误。
- 多重比较曲线采用全真零且独立的精确 FWER；Bonferroni 的一般上界另行说明，不混用 FDR。
- OLS 最小化竖直残差平方和。最优解按钮写入完整精度数值并可恢复，不用滑块舍入；不对手动直线错误地套用 R²=r²。
- 分组示例两组复用同一噪声以突出位移，已经明示其合成机制。
- t 的画幅外临界值有提示。功效曲线按各自尺度采样，防止 SE 很小时漏掉远处的窄峰。
- 导出标题/名称/参数对应当前子演示；错误时保留最后有效快照。表格预览最多 200 行，CSV 输出全部行。

## 开发与验证

```sh
npm ci
npm test
npm run check:assets
python -m http.server 8080 --directory dist
npm run build:portable -- "release/统计课堂-单文件.html"
```

Windows PowerShell 可用 npm.cmd。独立数值审查另需 NumPy/SciPy，二者不是网页依赖：

```sh
python validation/audit.py
python validation/audit-v2.py
python validation/audit-v3.py
```

本版 Node 39 组测试通过。基础 SciPy 对照 4108 项，v2 扩展 2265 项，高级模块新增 1359 项；Python 3.14.3 / SciPy 1.18.0。覆盖 t 分位点、比例区间、功效、多重比较、均值区间、Bootstrap、分组和 OLS。固定有限例通过不代表普遍精度保证。

新增正态功效、比例端点等最大绝对差约 10⁻¹⁵；t 临界值约 6.1×10⁻⁸。极端数据、极小样本的宽 t 区间放大后最大端点绝对差约 1.3×10⁻⁵，按脚本绝对+相对容差验收。不能统一声称所有方法误差小于 10⁻¹²。报告保存实际误差和源码 SHA-256。

v2 历史浏览器检查覆盖：18 路由的三标签、SVG、KaTeX、表格、错误栏；比例 k>n、零方差、Bayes 零分母、t df=1、功效 δ=0、OLS 精度恢复、Bootstrap 复现和完整 CSV、移动导航、投影退出、离线文档下载。详细证据随发布交付包保存。

**边界：** 单文件在没有同目录运行资源的独立服务中检查，未将自动化不能验证的 file://、另一台实体电脑、所有浏览器或真实教室设备宣称为已验收。单文件设计上支持双击打开，教室首次使用仍需实际试用。

## 后续维护

新增演示先在 stats-extra.js 写纯计算与必要边界测试，再在 extra-labs.js 注册目录和 renderer，复用 scaffold/bind/table/setMath。先计算和校验，再 init 图形，防止出错时清空有效结果。同步首页数量、文档与导出名称。新增 t 检验功效需非中心分布或明确模拟，不能简单平移中心 t。

发布使用独立整理的公开 checkout，不上传 node_modules、Sites 元数据/凭据/运行目录、临时研究文件或其他项目。源代码已提供；查看部署说明了解 main 与 gh-pages 的更新关系。

## v3 教材扩展实现

- `dist/stats-advanced.js`：UMD 纯计算，含小矩阵消元/逆、Jacobi 特征值、OLS、Lloyd、层次链接、模型协方差、整行 Bootstrap、已知方差汇聚与增长参数转换。无新增依赖。
- `dist/advanced-labs.js`：14 章目录及 28 个演示。`installAdvanced()` 在 app 初始化路由前把章节加入 topics / chapterModules；`#textbook` 是独立教材页。每个新增章节用 `#章节id` 和 `#章节id/explore`，完整表见教材覆盖说明。
- 保留原 18 路由、storageKey 与参数结构。高级模块分别存储；旧书签继续可用。首页基础卡片筛除 advanced 项，新增教材入口。
- 加载顺序：stats-core → stats-extra → stats-advanced → advanced-labs → 图形/控件/资源/extra-labs → app。高级文件的函数在 app 定义完成后调用。
- 修改计算后运行 `npm.cmd test` 和 `python validation/audit-v3.py`。当前 39 个测试组通过；高级模块 1,359 个 NumPy/SciPy 标量对照通过，最大绝对误差约 2.54e-11。原有两份 oracle 保留。
- 已修复 SEM 极小 p 值的 CDF 相减损失：χ²₁ 尾部转为稳定正态尾积分。不要退回 `1-cdf`。
- Bootstrap 分位数明确 type 7；所有重抽样按整行进行并重拟合。增长时间中心化同时变换截距方差和截距—斜率协方差。
- docs 与 dist/docs 现在含四份 MD，check-assets 同时核验；单文件自动内嵌四份文档。

高级纯函数设计为受控课堂参数范围，界面负责范围约束；不是任意数据或任意维度的数值库。矩阵逆采用带部分主元的消元，近奇异即报错，没有用正则化偷偷改变统计检验。新增通用拟合器前应另做稳健算法与错误处理设计。

验证证据随 v3 交付包提供：28 个新页及 18 个旧页的浏览器加载、代表性参数交互、窄屏检查、CSV/SVG/文档导出与在线文件校验。并未在另一台物理电脑上现场验收；单文件的独立资源检查与独立目录运行不能替代该项。
